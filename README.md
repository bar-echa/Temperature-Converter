# Temperature Converter (Celsius • Fahrenheit • Kelvin)

A simple Windows Forms application built in C# using Visual Studio 2022.  
This tool allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin using a clean UI and interactive controls.

## Features
- Convert between Celsius, Fahrenheit, and Kelvin
- Dynamic UI updates
- State-based temperature switching
- Clean and simple design

## Technologies Used
- C#
- .NET Framework / Windows Forms
- Visual Studio 2022

## How to Run
1. Clone the repository:
   git clone https://github.com/bar-echa/Temperature-Converter

2. Open the solution file:
   TempConv.sln

3. Build and run the project in Visual Studio 2022.
